# Result Effect Assets

Put result effect GIFs in this folder:

- `sparkle.gif` appears above rewarded characters.
- `explosion.gif` appears above slashed characters.
- `talking-bubble.gif` appears only after two characters meet for discussion.
- `thought-cloud.gif` appears above a character that is stopped and researching alone.

Result effects are shown only while the final result screen is open. Discussion and research effects are shown only when characters are stopped in the matching state. If a file is missing, that effect is hidden without showing a broken image.
